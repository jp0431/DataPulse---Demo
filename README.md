# 📊 DataPulse MVP

MVP de una herramienta ligera para análisis y visualización de datos de forma rápida y sencilla.

La idea de este proyecto es permitir a cualquier usuario explorar datasets y generar gráficos sin necesidad de configurar notebooks, pipelines o herramientas complejas de BI.

## 🧠 Qué hace esta demo

Esta versión MVP permite:

- Cargar archivos de datos
- Explorar datasets de forma rápida
- Generar visualizaciones básicas automáticamente
- Realizar análisis exploratorio sencillo sin configuración

---

## ❌ Funciones desactivadas en la demo

Para esta versión pública se han limitado algunas funcionalidades:

- Límite de subida de archivos: **10 MB**
- Descarga de gráficos desactivada
- Generación y descarga de reportes desactivada

Estas restricciones solo aplican a la demo.

---

## 🎯 Objetivo del proyecto

Este MVP busca validar si existe valor en una herramienta ligera que permita:

- Reducir el tiempo de análisis exploratorio
- Evitar setups complejos para tareas simples
- Ofrecer insights rápidos desde datos crudos
